# 1. 文档介绍

## 1.1 项目背景

随着智能汽车和车联网技术的发展，车辆状态监控、车主身份认证、车辆信息管理及智能化服务逐渐成为汽车应用的重要功能。

为了学习和实践 Android 车载应用开发、前后端分离架构及车辆数据管理技术，本项目设计并开发 DriveOS 车载智能助手与车辆状态监控平台。

本项目以模拟车辆数据为基础，构建集用户注册登录、模拟车主认证、车辆绑定、车辆状态展示、告警管理、行程记录及智能助手于一体的应用系统，同时提供 Web 管理后台，实现用户、车辆及绑定关系的统一管理。

## 1.2 项目目标

本项目旨在实现一个具有完整业务流程的车载应用 Demo，主要目标如下：

1. 实现基于手机号的用户注册、登录及身份认证。
2. 实现模拟车主身份核验，验证用户与测试车辆之间的归属关系。
3. 实现车辆绑定、解绑及已绑定车辆查询。
4. 实现车辆状态、告警信息、行程记录等数据的展示与管理。
5. 建立 Android 客户端、Java 后端和 Web 管理后台之间的数据交互机制。
6. 通过身份认证、资源级权限校验和数据库约束，保障车辆数据访问的安全性。
7. 为后续接入真实车企数据平台、扩展车载功能及适配车载设备预留技术基础。

## 1.3 项目范围

本项目由三个主要部分组成。

### 1.3.1 Android 客户端

Android 客户端面向普通用户，采用 Kotlin 与 Jetpack Compose 开发，主要包括：

- 用户注册与登录
- 模拟车主认证
- 车辆绑定与解绑
- 我的车辆与车辆详情
- 车辆状态监控
- 告警中心与行程记录
- 个人中心与应用设置
- 智能助手交互界面

### 1.3.2 Java 后端服务

后端采用 Java、Spring Boot 与 MySQL 开发，负责业务处理、数据持久化和接口访问控制，主要包括：

- 用户账户与身份认证
- JWT 登录状态管理
- 模拟车主身份核验
- 车辆信息与绑定关系管理
- 车辆状态、告警及行程数据接口
- 用户与车辆之间的资源权限校验
- 统一异常处理及操作日志

### 1.3.3 Web 管理后台

Web 管理后台面向系统管理员，采用 Vue 3、TypeScript 与 Element Plus 开发，主要包括：

- 系统登录
- 用户管理
- 车辆信息管理
- 模拟车主测试数据管理
- 车辆绑定关系查询
- 告警信息管理
- 行程数据管理
- 车辆状态统计
- 系统操作日志

## 1.4 技术实现说明

项目采用前后端分离架构。Android 客户端和 Web 管理后台通过 HTTP REST API 与 Java 后端交互，后端通过 MyBatis-Plus 访问 MySQL 数据库。

Android 客户端负责页面展示、用户交互和客户端状态管理；Java 后端负责身份认证、业务规则、数据处理及权限校验；Web 管理后台负责系统数据维护和管理操作。

车辆状态、告警和行程数据在 Demo 阶段使用模拟数据生成，不代表真实车辆实时数据。模拟车主认证仅用于演示业务流程，不接入真实机动车登记数据库，也不代表真实车主身份核验。

## 1.5 适用范围

本文档用于指导 DriveOS 项目的需求分析、UI 原型设计、前后端开发、接口联调、数据库设计、功能测试及项目部署。

本文档主要面向项目开发人员、测试人员及项目学习者，可作为项目实现、功能验收和后续扩展的参考依据。
